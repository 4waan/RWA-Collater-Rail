# RWA Credit Rail v1.0.0

RWA Credit Rail v1.0.0 is the submission release of the bilateral HBAR
financing scaffold for ATS securities.

## Verified lifecycle

The committed
[`reference-testnet.json`](../packages/foundry/deployments/reference-testnet.json)
contains a schema version 3 Hedera testnet lifecycle with 17 Mirror-confirmed
transactions, two HSS schedules, two distinct ATS holds, one repayment, and one
matured HSS default. The
[public proof audit](findings/2026-09-27-public-proof-link-audit.md) records every
authoritative Mirror source and the dated HashScan availability result.

Final contract assertions are bound to Hashio block `41012411`. Rail solvency
is checked separately against a typed current Mirror account balance. The
[balance-source finding](findings/2026-09-27-historical-rail-balance.md) explains
why these proof classes must remain distinct.

## Supported boundary

This release supports bilateral HBAR principal and repayment against one ATS
security token and partition. It includes ATS hold custody, internal KYC
ordering, immutable policy bounds, HIP-475 settlement conversion by default,
optional explicitly configured Pyth conversion, HSS maturity automation,
permissionless settlement fallback, public evidence validation, and reference
mode without a wallet.

It is not an exchange, order book, pooled lender, security valuation engine,
identity provider, or production custody approval. No independent production
audit is claimed. HTS settlement, the external KYC adapter, and experimental
CLPR mobility begin only after this HBAR release is tagged and submitted.

## Assurance

The release gate includes formatting, linting, type checks, deterministic
Foundry tests, fuzz tests, adversarial invariants, runner tests, browser tests,
production build, route checks, ABI checks, secret scans, Harness validation,
and a clean generated scaffold. The exact assurance boundary is documented in
the [security policy](../SECURITY.md) and
[submission checklist](submission-readiness.md).
